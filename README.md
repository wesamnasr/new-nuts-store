# 🌰 محمصة الواحة الذهبية | New Nuts Store

متجر إلكتروني متكامل باللغة العربية (RTL) لبيع أفخر أنواع المكسرات الطازجة، بوكسات الهدايا والمشكل، والفواكه المجففة، مبني باستخدام **Next.js 15 (App Router)** و **TypeScript** و **Tailwind CSS**.

## ✨ أبرز المميزات (Key Features)

### 1. تجربة تسوق متخصصة للمكسرات 🥜
- **تعدد الأوزان ودرجات التحميص:** اختيار الوزن (`250 جم`، `500 جم`، `1 كجم`) ونوع التحميص (`محمص مملح`، `محمص بدون ملح`، `نيء طبيعي`، `مدخن بالتوابل`) مباشرة من بطاقة المنتج أو صفحة المنتج مع تحديث لحظي للسعر.
- **ميزة "كوّن علبتك بنفسك" (`Build Your Own Mix Box`):**
  - اختيار سعة العلبة (`500 جم`، `1 كجم`، أو `2 كجم`).
  - توزيع نسب الأصناف المختارة ودرجات تحميصها حتى اكتمال السعة `100%`، أو استخدام التوزيع المتساوي بضغطة زر.
  - حساب السعر الفعلي تناسبياً حسب أسعار الأصناف المختارة وعرض تفصيل الخلطة في السلة، الدفع، تتبع الطلب، والفاتورة.

### 2. صفحات منتجات متوافقة مع محركات البحث (SEO) وتقييمات حية ⭐
- مسارات مستقلة لكل منتج (`/products/[slug]`) مع توليد تلقائي لبيانات `OpenGraph` و `Schema.org Product JSON-LD`.
- بطاقة الحقائق الغذائية التفصيلية لكل `100 جم` (السعرات، البروتين، الدهون الصحية، الكربوهيدرات، الألياف).
- نظام تقييمات ومراجعات تفاعلي (`POST /api/reviews`) يحفظ آراء العملاء ويُحدث متوسط التقييمات فورياً.

### 3. سلة مشتريات ذكية وإتمام طلب سريع 🛒
- شريط تقدم تفاعلي للشحن المجاني التلقائي عند تجاوز الحد المحدد (مثلاً `1000 ج.م`).
- حساب تكلفة الشحن تلقائياً حسب المحافظة داخل مصر مع التحقق من صحة أرقام الهواتف المصرية (`010`, `011`, `012`, `015`) ودعم الأرقام العربية والإنجليزية.
- دعم أكواد الخصم الترويجية (نسبة مئوية أو مبلغ ثابت) مثل `NUTS10` و `WELCOME50`.
- تعدد وسائل الدفع: الدفع عند الاستلام (`COD`)، تحويل `InstaPay`، أو محفظة `فودافون كاش`، مع زر إرسال فاتورة الطلب عبر **واتساب** للتأكيد الفوري.

### 4. نظام تتبع الطلبات للعملاء 📦
- البحث برقم الطلب (مثال: `NUT-1001`) أو رقم الهاتف لمتابعة مراحل تجهيز الطلب:
  *(تم الاستلام ⬅️ تم التأكيد ⬅️ جاري التحميص والتغليف الطازج 🔥 ⬅️ خرج مع المندوب 🚚 ⬅️ تم التسليم ✅)*.

### 5. لوحة تحكم شاملة ومحمية للتاجر (Admin Dashboard) ⚙️
- **حماية وأمان:** تسجيل دخول محمي بتوقيع `HMAC-SHA256` وكوكيز `httpOnly`، مع حماية جميع مسارات التعديل (`PUT /api/store` و `PATCH /api/orders`) وإعادة حساب أسعار الطلبات في الخادم لمنع أي تلاعب.
- **إدارة الكتالوج والطلبات:** إضافة وتعديل المنتجات وأسعار الأوزان، إدارة الأقسام، تحديث حالات الطلبات، تعديل أسعار شحن المحافظات، وإدارة الكوبونات.
- **طباعة الفواتير وتصدير البيانات:**
  - طباعة فاتورة عربية احترافية مقاس `A4` لأي طلب (`@media print`).
  - تصدير سجل الطلبات إلى ملف `CSV` بترميز `UTF-8 BOM` متوافق مع اللغة العربية في برنامج **Excel** ومحصن ضد حقن المعادلات (`CWE-1236`).

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Framework:** Next.js 15 (App Router, Server & Client Components)
- **Language:** TypeScript 5
- **Styling:** Tailwind CSS 3 + خط `Cairo` العربي من Google Fonts
- **Icons:** Lucide React
- **Database & Storage:** **Neon Serverless Postgres** (`@neondatabase/serverless` عبر `DATABASE_URL` على Vercel لحفظ دائم لجميع بيانات المتجر والطلبات والتقييمات، مع تراجع تلقائي إلى `data/store-db.json` عند التشغيل المحلي بدون اتصال سحابي)
- **Testing:** Node.js Test Runner (`scripts/verify.mjs` - 54 اختباراً آلياً شاملاً)

## 🚀 طريقة التشغيل محلياً (Getting Started)

1. **تثبيت الحزم:**
   ```bash
   npm install
   ```

2. **تشغيل خادم التطوير المحلي:**
   ```bash
   npm run dev
   ```
   ثم افتح المتصفح على الرابط: `http://localhost:3000`

3. **تشغيل حزمة الاختبارات الآلية (`54/54`):**
   ```bash
   npm test
   ```

4. **بناء نسخة الإنتاج (Production Build):**
   ```bash
   npm run build
   npm start
   ```
