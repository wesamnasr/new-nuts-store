# ☕ محمصة حفصة للبن والمكسرات | HAFSA ROASTERY

منظومة تشغيل وتجارة موحّدة (**Omnichannel Retail ERP + POS + E-Commerce**) باللغة العربية (`RTL`) لـ **محمصة حفصة للبن والمكسرات — فرع بني مزار (أمام مسجد الزراعيين - المنيا)**، مبنية باستخدام **Next.js 15 (App Router)** و **TypeScript** و **Tailwind CSS** و **Neon Serverless Postgres**.

## ✨ أبرز المميزات التشغيلية والتجارية

### 1. تجربة متجر إلكتروني متخصصة للبن والمكسرات 🥜☕
- **تعدد الأوزان ودرجات التحميص:** اختيار الوزن (`ثمن 125 جم`، `ربع 250 جم`، `نصف 500 جم`، `كيلو 1000 جم`، `2 كجم`) ودرجة التحميص فورياً مع حساب لحظي للسعر.
- **بوكسات السهرة المقسمة (`Partitioned Boxes`) وبوكس النسب الحرة:** تصميم بوكس `روقان (4 خانات)`، `العيلة (6 خانات)`، أو `VIP الملكي (6 خانات)` مع حماية برمجية آلية لهامش الربح.
- **استوديو توليفة البن (`Custom Coffee Blender`):** تحديد نسب البن (برازيلي، كولومبي، هندي، حبشي)، درجة التحميص، التحويجة الملكية، ونوع الطحنة مع طباعة ملصق الباريستا.
- **منظومة التوصيل الثلاثية:** توصيل فوري لبندر بني مزار (`30 - 45 دقيقة`)، دورات توزيع مجدولة لقرى المركز (`2:00 ظهراً` و`8:00 مساءً`)، استلام سريع من الفرع، وشحن لكافة المحافظات.

### 2. محطة كاشير الفرع ونقطة البيع الاحترافية (`/pos`) ⚖️
- **6 شاشات داخلية سريعة (`F1..F6`):** البيع المباشر، البوكسات، توليفة البن، سجل الفواتير، ملخص الوردية والمصروفات، وطابور طلبات الأونلاين.
- **دعم ميزان الباركود الإلكتروني (`EAN-13`):** قراءة فورية لملصقات الميزان بصيغة `20PPPPWWWWWC`، بالإضافة لحاسبة البيع بالجرام أو البيع بمبلغ محدد (`عايز بـ 50 جنيه`).
- **طباعة حرارية قياسية:** دعم طباعة بون الكاشير وتقرير إغلاق الوردية (`Z-Report`) بمقاس `80mm`، وطباعة استيكر الباريستا والبوكسات بمقاس `58mm`.

### 3. عزل الأدوار، التوريد، والرقابة المحاسبية 🛡️
- **شاشة دخول موحدة آمنة:** مصادقة محمية بتوقيع `HMAC-SHA256` وتشفير `scrypt` وتوجيه تلقائي حسب الصلاحيات بدون كشف أي بيانات دخول أو محدد أدوار على الواجهة.
- **عزل كامل للتكاليف والأرباح:** الكاشير والمندوب معزولان تماماً عن أسعار الجملة وصافي الربح، بينما يمتلك المحاسب لوحة تدقيق مالي للقراءة فقط (`Read-Only Audit`) وتصدير تقارير `Excel/CSV` بترميز `UTF-8 BOM` محصن ضد `CWE-1236`.
- **اعتماد فواتير التوريد:** يرفع المورد مسودات فواتير التوريد عبر `/supplier`، وعند اعتماد المدير العام تزيد أرصدة المخزون (`stockKg`) وتتحدث تكلفة الجملة ذرياً.

## 🛠️ التقنيات المستخدمة

- **الإطار البرمجي:** Next.js 15 (App Router) + React 19 + TypeScript 5
- **الهوية البصرية:** Tailwind CSS 3 بثيم محمصة حفصة الرسمي الموحد (`#FAF6F0` رخامي دافئ • `#231710` إسبريسو • `#C88A4B` عسلي • `#D4AF37` ذهبي ملكي) + خط `Cairo`
- **قاعدة البيانات:** Neon Serverless Postgres (`@neondatabase/serverless`) مع تراجع آمن للتشغيل والاختبار المحلي
- **الاختبارات الآلية:** `scripts/verify.mjs` (حزمة اختبارات شاملة تتحقق من المنطق، الأمان، عزل الصلاحيات، وسلامة بناء الإنتاج)
